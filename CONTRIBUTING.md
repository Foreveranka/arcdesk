# Contributing to arcdesk

Thanks for taking a look. This is a small project by one person, so the process is light.

## Reporting a problem
Open an issue with what you did, what you expected, and what happened. For anything that
touches funds or keys, please email instead of opening a public issue.

## Proposing a change
1. Open an issue first if the change is more than a small fix, so we can agree on the shape.
2. Fork, branch from `main`, keep the change focused.
3. Run the existing tests and add one for anything you fix or add.
4. Open a pull request that says what changed and why. Short is fine.

## Style
Match the surrounding code. No reformatting-only commits.
